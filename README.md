# Python Bootcamp Exercises

A collection of learning exercises covering Python fundamentals, control flow, functions, classes and small practice projects.

## Examples

- [Text adventure](AvventuraTestualeGA.py)
- [Food ordering exercise](FoodOrderSystem.py)
- [Battleship exercise](GiuseppeA_Battaglia_navale.py)
- [TropicTaste project](BitcampRepository/TropicTaste_finalProject.py)

These are independent exercises, not one packaged application. Some scripts require interactive input, local datasets or additional libraries. There is no shared installation or automated test suite documented for the collection.

For my applied analytics projects, see my [GitHub profile](https://github.com/joelambga-cpu).
